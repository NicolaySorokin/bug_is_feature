# Архитектура в Archi

[edu-crm.archimate](edu-crm.archimate) — модель системы в нотации
ArchiMate 3.1 для [Archi](https://www.archimatetool.com) (раздел 6, п. 7 ТЗ).
Открывается в Archi: File → Open.

Три представления:

| Представление | Что на нём |
| --- | --- |
| 1. Бизнес-контекст | роли (менеджер, руководитель, администратор), вуз, процесс взаимодействия из 14 этапов, отчётность; взаимодействие с вузом — центральный объект, в нём договор (0..1), ИТ-программы, продукты и лицензии; заявка на обучение, обучающийся |
| 2. Приложения | прикладные сервисы (вход и роли, взаимодействия, рабочий процесс, отчёты, статистика, загрузка из Excel, администрирование, обмен с LMS и сайтом), клиентская часть, API, Keycloak, LMS и сайт, данные CRM и файлы |
| 3. Развёртывание | сервер Linux с Docker Compose, контейнеры (Nginx с клиентской частью, API, Keycloak, PostgreSQL), образы, тома данных, GitHub Actions, системный администратор |

Модель собирает скрипт [generate.py](generate.py): её удобно править
в коде и сравнивать версии в git. Идентификаторы элементов постоянные,
поэтому после пересборки Archi узнаёт те же элементы.

```bash
python docs/architecture/generate.py
```

Правки, сделанные прямо в Archi, при пересборке пропадут — переносите
их в `generate.py`.
