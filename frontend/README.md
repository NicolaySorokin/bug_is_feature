# IT School CRM — frontend

React + TypeScript + Vite-интерфейс для CRM взаимодействия Ростелекома с университетами.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию приложение обращается к `http://localhost:8000/api/v1`. Если backend недоступен, включается демонстрационный сценарий с тестовыми данными, чтобы можно было показать основные экраны и workflow.

Переменные окружения:

- `VITE_API_BASE_URL` — адрес API;
- `VITE_USE_DEMO_FALLBACK=false` — отключить demo-fallback.

## Экраны

- обзор с KPI, рисками, нагрузкой команды и журналом активности;
- реестр договоров с поиском и фильтром статуса;
- карточка договора: реквизиты, университет, программы, продукты, файлы;
- визуальный workflow со статусами этапов, переходами, блокировкой и историей;
- университеты, отчёты с фильтрами и экспортом;
- экраны-заглушки интеграций и администрирования с перечислением backend API.

Для dev-auth backend используются `X-Dev-User` и `X-Dev-Roles`; выбранный demo-пользователь меняется в правой части верхней панели.
